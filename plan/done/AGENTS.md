# Archivo histórico: no usar para trabajo actual

No leer estos documentos para desplegar, configurar, planificar nuevas funciones,
implementar o revisar el estado actual. Solo pueden consultarse por una petición
explícita del usuario de investigación histórica (fechas, motivos o evolución).

Sus comandos, estados, conteos de pruebas y capacidades corresponden a la base indicada;
no son instrucciones vigentes ni tareas pendientes. No reabrir un documento cerrado.
