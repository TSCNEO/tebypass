# Documentación operativa

Este directorio solo contiene guías vigentes para usuarios y agentes de despliegue.
No crear aquí planes, roadmaps, auditorías, descubrimientos ni cronologías.

Para desplegar, seguir LLM_DEPLOYMENT.md. No consultar plan/, plan/done/, maintenance/
ni versiones de planes en Git. Lo propuesto o archivado no acredita capacidades actuales.
Actualizar las guías al cambiar comportamiento y comprobar versión instalada, código y
contrato autenticado cuando se necesite resolver una discrepancia.
