Ajustes

El router aplica una política de salida hacia la VPN elegida. El gateway virtual permite hacerlo cuando el router no ofrece políticas de enrutamiento.

Crea antes una tabla FIB con ruta por defecto hacia tu VPN. Las reglas usan lookup-only-in-table. FastTrack y otras reglas mangle deben respetar esta política.

Prepara una regla en Firewall → Rules [new] / Automation → Filter con esta descripción, el alias indicado como destino y tu gateway VPN. TeByPass gestiona el alias y activa o desactiva esa regla.

Si se desmarca, se eliminan las rutas del router automáticamente y se pausa la sincronización.

300 = cada 5 minutos. 0 = solo cambios manuales.
